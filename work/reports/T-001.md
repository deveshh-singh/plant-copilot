## In plain words
The project is now a real Python project: one command installs everything
(`uv sync`), one runs the tests (`uv run pytest -q`) and one checks code style
(`uv run ruff check .`). The tests can start a small Spark engine on the Mac, so
every later card can test its PySpark logic offline before it touches Databricks.

## Deviations
- **Ruff excludes `.claude/`** (`extend-exclude` in `pyproject.toml`). Ruff 0.16.9's default rule
  set is wider than older releases, and it flagged 17 issues, all in `.claude/workflow/board.py`,
  which is workflow-owned and must not be edited. Our own code passes the full default set.
- **Added `[tool.uv] package = false`** so uv treats this as an app, not an installable package
  (no build backend needed). Because it is not installed, I added `pythonpath = ["."]` to the
  pytest settings: a throwaway test with `import pipelines` failed at collection without it and
  passed with it (the file was deleted afterwards).
