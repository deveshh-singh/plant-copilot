# T-005 — load_cmapss job: Delta tables, comments, data checks

Built by: **Claude (builder account)**. Runs on the owner's Free Edition workspace (dev target).

## Goal
`databricks bundle run -t dev load_cmapss` reads the 12 files from the volume, writes
`workspace.plant_bronze.cmapss_raw` and the three `workspace.plant_silver` tables as Delta,
puts a comment on every table and column, then a check task fails the job if any data check
fails. This completes M1.

## Read first
- Plan `work/plans/m0-m1-setup-and-data.md` ("Layout")
- `pipelines/cmapss.py`, `pipelines/cmapss_schema.py` (function signatures only)
- `databricks.yml`, `resources/setup.job.yml` (pattern for a serverless job)
- `data/raw/cmapss/MANIFEST.json` (line counts per file, from T-003; read the counts only)

## Decisions already made
- Reader: `spark.read.text("/Volumes/workspace/plant_bronze/raw/cmapss/")` with
  `_metadata.file_name` as `source_file` and a line index that keeps file order (for RUL lines).
- Writes: `mode("overwrite")`, `overwriteSchema=true`: reruns are idempotent.
- Comments: `COMMENT ON TABLE` and `ALTER TABLE ... ALTER COLUMN ... COMMENT`, generated by a
  pure function in `pipelines/comments.py` from `cmapss_schema` (unit-tested for quoting of `'`).
- Notebooks import `pipelines` from the bundle's synced files (add the bundle root to `sys.path`
  in the notebook; no wheel yet).
- Job `load_cmapss`: task `load` (10_load_cmapss.py) → task `check` (11_check_cmapss.py), serverless.
- Expected counts are **checks, not results**: the readme gives train/test engines FD001 100/100,
  FD002 260/259, FD003 100/100, FD004 248/249. Rows are checked against the T-003 manifest line counts.
  Only counts measured in the run go in the report (rule 2).

## Spec
Check task (raises with a list of failures; prints one line per check):
1. bronze rows per `source_file` for train/test files = manifest line counts (passed as job parameters or a small JSON in the volume: builder's call)
2. silver `sensor_readings` rows = bronze train+test rows
3. engines per (dataset, split) = readme counts above
4. no nulls in `engine_id`, `cycle`, `rul`; no duplicate (engine_id, cycle)
5. `rul >= 0`; for test engines, `rul` at the last cycle = `true_rul`
6. every column of the 4 tables has a non-empty comment (`DESCRIBE TABLE EXTENDED` / `information_schema.columns`)
7. prints `sensor_readings` schema and 5 sample rows (`LIMIT 5`)
