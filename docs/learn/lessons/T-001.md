# T-001 — uv project, pytest with local Spark, ruff: what you just built

## In plain words
The repo is now a working Python project. `uv sync` installs the exact same library
versions on any machine, `uv run pytest -q` runs the tests, and `uv run ruff check .`
checks the code style. The tests start a tiny Spark engine on your Mac, so PySpark
logic can be checked in seconds, offline, before it goes near Databricks.

## The idea behind it
Spark is the engine Databricks runs your DataFrame code on. Normally it spreads the
work over many machines; `local[1]` runs it inside one process on one CPU core, like
test-driving a truck in the car park before taking it on the motorway. The code is
the same, so a transform that passes here behaves the same on Databricks (the data is
just smaller). Spark runs on the JVM (Java Virtual Machine, the engine that runs Java
programs), and PySpark 4 needs Java 17. A **fixture** is something pytest builds once
and hands to any test that asks for it by name; `scope="session"` means one Spark for
the whole test run, because starting Spark takes a few seconds.
Why not test on Databricks directly? Every test run would need the network and a
serverless start, and would take much longer than the ~8 s it takes now (D-006).

## Where it lives
```python
HOMEBREW_JDK17 = Path("/opt/homebrew/opt/openjdk@17")
if "JAVA_HOME" not in os.environ and HOMEBREW_JDK17.exists():   # ← Java not set up? use Homebrew's
    os.environ["JAVA_HOME"] = str(HOMEBREW_JDK17)

@pytest.fixture(scope="session")                   # ← built once, shared by all tests
def spark():
    session = (
        SparkSession.builder.master("local[1]")    # ← Spark on this Mac, one core
        .config("spark.ui.enabled", "false")       # ← no web dashboard: faster, no port clash
        .config("spark.sql.shuffle.partitions", "1")  # ← default 200 is overkill for 3 rows
        .getOrCreate()
    )
    yield session                                  # ← tests run here
    session.stop()                                 # ← cleaned up at the end
```
File: `tests/conftest.py` (lines 8–27)
