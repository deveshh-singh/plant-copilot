# T-003 — Fetch C-MAPSS: what you just built

## In plain words
`scripts/fetch_cmapss.py` gets the NASA engine data onto your Mac in one command and proves
it arrived whole: all 12 files present, each with a size, line count and fingerprint in
`data/raw/cmapss/MANIFEST.json`. Later it copies the same files into Databricks.

## The idea behind it
- **Caching / idempotent** (safe to run again and again with the same result): the script
  only downloads if the zip isn't already on disk. Like checking the fridge before shopping.
- **sha256 checksum**: a 64-character fingerprint of a file's bytes. Change one byte and the
  fingerprint changes completely, so it proves "this is exactly the file we tested with".
- **Nested zip**: NASA's zip holds another zip inside. The code calls itself on any inner
  zip (recursion) until it finds the `.txt` files, so it works whichever layout NASA uses.
- Why test on tiny fake zips instead of the real 12 MB download? Tests run in milliseconds,
  never need the internet, and can fake broken cases (a missing file) on purpose.

## Where it lives
```python
def _extract_from(zf, out_dir):
    for info in zf.infolist():                    # ← every entry in the zip
        name = Path(info.filename).name           # ← drop folder names
        if name in EXPECTED_FILES:                # ← one of the 12 we want
            (out_dir / name).write_bytes(zf.read(info))
        elif name.lower().endswith(".zip"):       # ← a zip inside the zip
            with zipfile.ZipFile(io.BytesIO(zf.read(info))) as inner:
                _extract_from(inner, out_dir)     # ← same function, one level down
```
